title: "Contracts"
description: "Three contracts, one line each."
---

| Contract | Role |
| --- | --- |
| `KnotHook.sol` | Hook-owned constant-product pool with proportional ERC-20 LP shares |
| `KnotFederation.sol` | Authenticated per-member reserves plus the O(1) aggregate pair |
| `KnotMath.sol` | Fee-aware exact-input and exact-output quoting, rounding against the taker |

## KnotFederation

<ResponseField name="preview" type="view">
  Returns `(localQuote, aggregateQuote, knotQuote)` without mutating state. The read used by the
  frontend and by any integrator.
</ResponseField>

<ResponseField name="executeSwap" type="onlyMember">
  Quotes and atomically updates both the member book and the aggregate.
</ResponseField>

<ResponseField name="reservesOf" type="view">
  One member's reserve pair.
</ResponseField>

<ResponseField name="register / unregister" type="onlyOwner">
  Membership management, bounded by an immutable member cap. Only an empty member may release its slot.
</ResponseField>

## KnotHook

<ResponseField name="activatePendingLiquidity" type="external">
  Activates the caller's matured deposit at the current reserve ratio.
</ResponseField>

<ResponseField name="cancelPendingLiquidity" type="external">
  Cancels the caller's inactive deposit without touching active liquidity.
</ResponseField>

<ResponseField name="claimLiquidityRefund" type="external">
  Withdraws all assets currently refundable to the caller.
</ResponseField>
